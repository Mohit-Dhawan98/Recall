<objective>
Set up frontend test infrastructure: vitest configuration, shared render utility, test fixtures, and MSW handlers.

Purpose: All component tests depend on this foundation. Without vitest config, no tests run. Without shared utilities, every test file would duplicate provider wrapping and mock data.
Output: Vitest configured, renderWithProviders utility, shared fixtures, shared MSW handlers -- all verified by a smoke test.
</objective>

<task>
  <name>Task 1: Add vitest test config to vite.config.ts and create test utilities</name>
  <files>
    frontend/vite.config.ts
    frontend/src/test/test-utils.tsx
  </files>
  <action>
1. Add `/// <reference types="vitest" />` at the top of `frontend/vite.config.ts` and add `test` property to defineConfig:
   ```
   test: {
     globals: true,
     environment: 'jsdom',
     setupFiles: './src/test/setup.ts',
     css: true,
   }
   ```

2. Create `frontend/src/test/test-utils.tsx` with:
   - `createTestQueryClient()`: Returns new `QueryClient` with `defaultOptions: { queries: { retry: false, gcTime: Infinity }, mutations: { retry: false } }`
   - `renderWithProviders(ui, options?)`: Wraps `ui` in `QueryClientProvider` (new client per call) and `MemoryRouter` (accepts optional `initialEntries`). Returns RTL `render()` result plus the `queryClient`.
   - Re-export everything from `@testing-library/react`
   - Export `userEvent` from `@testing-library/user-event`
  </action>
  <verify>
    Run `cd frontend && npx vitest run --passWithNoTests` -- should exit 0.
  </verify>
</task>
