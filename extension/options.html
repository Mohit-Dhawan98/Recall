Configure your connection to the Recall server

Server Configuration

The URL where your Recall server is running (e.g., your tunnel URL)

Find this in your Recall web app under Settings

Setup Instructions

  1. Start your Recall server with docker-compose up
  2. Set up a tunnel (Cloudflare, Tailscale, or ngrok) for remote access
  3. Enter your tunnel URL above (e.g., https://recall.example.com)
  4. Get your API key from the Recall web app Settings page
  5. Click "Test Connection" to verify everything works
